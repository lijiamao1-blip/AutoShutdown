## 2. 职责边界（为何迁出）

- **T03/T04 遗留**：`SchedulerEngine.TryRestoreAsync` 曾内联「瞬态实例中断 + 持久化」，把「恢复」与「调度循环启动」耦合在引擎内部。
- **迁出后**：引擎在 `TryRestoreAsync` 中只做 `LoadAsync` → 处理 `NotFound/Success/Migrated/Corrupt/IoFailure/Invalid/UnsupportedVersion` → `Success/Migrated` 时直接建立初始快照；**不再做任何状态机中断、不再为恢复写盘**。
- **恢复职责**归 `CrashRecoveryManager`（Core，纯逻辑，不写日志、不触发通知、不接触电源），启动链在调度循环前同步执行，保证瞬态实例先被标 `Interrupted` 再启动调度，绝不被当作在途任务补执行。

## 3. 交付物

### 3.1 `CrashRecoveryResult`（新增）

- `CrashRecoveryStatus`：`Unknown / Recovered / NoRecoveryNeeded / NotFound / Corrupt / IoFailure / Invalid / UnsupportedVersion / TransitionRejected`。
- `CrashRecoveryResult`：`Status`、`State?`、`InterruptedTaskIds`（供审计 Warning）、`Errors`、`Succeeded`。

### 3.2 `CrashRecoveryManager`（新增，Core）

构造：`(IStorage, ITaskInstanceStateMachine, IClock)`。

`RecoverAsync` 流程：
1. `RuntimeStateStore.LoadAsync`（复用 FileStorage 的 NotFound/Corrupt/IoFailure 语义）。
2. `NotFound/Corrupt/IoFailure/Invalid/UnsupportedVersion` → 对应失败状态直通，**不写盘、不伪造空态回退**。
3. `Success/Migrated` → `TryInterruptTransientInstances`：遍历实例，`Running/Confirming/Executing` 经 `ITaskInstanceStateMachine.TryTransition(→ Interrupted, CrashRecovered)`；任一转换被拒（冻结白名单下不应发生）→ `TransitionRejected`。
4. 无瞬态实例 → `NoRecoveryNeeded`（不写盘）。
5. 有瞬态实例 → 以 `_clock.UtcNow` 建候选态，`SaveAsync` **写一次**；写失败 → `IoFailure`。
6. 返回 `Recovered` + `InterruptedTaskIds`。

- `Waiting` 保持 `Waiting`（由调度循环重算排程）；终态保持；`HasExecuted` 等字段在 `with { State = Interrupted }` 下原样保留。

### 3.3 启动链接线（`ApplicationLifetimeCoordinator`）

- `Start()` 顺序：`_logRetention.RunOnce()` → `RecoverFromCrash()` → `_pipeServer.Start()` → `RunAsync` → …。
- `RecoverFromCrash()`：同步 `GetAwaiter().GetResult()`；对被中断 taskId 逐条 `Warning("CrashRecovered", "崩溃恢复：任务 {taskId} 已标记为中断（interrupted），不补执行。")`；对 `Corrupt/Invalid/UnsupportedVersion/IoFailure/TransitionRejected` 记 `Error`；异常兜底记 `Error`。恢复失败**不阻断后续启动**（引擎对损坏态自会 fault，语义不变）。

### 3.4 DI 注册（`ServiceRegistration`）

- `services.AddSingleton<CrashRecoveryManager>();`（T05 卡未列但 DI 接线必需，属「最小越界适配」）。
- `ITaskArbitrator` 仍为 `NoOpTaskArbitrator`（T06 替换）。

| `Recover_Corrupt_ReturnsCorrupt` | `Corrupt`；写 0 次 |
