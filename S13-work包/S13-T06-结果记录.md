## 2. 设计决策（T06 契约冻结后的最小越界适配）

- **T04 已冻结** `ITaskArbitrator.Arbitrate(IReadOnlyList<TaskInstance> dueInstances, DateTimeOffset now)` 签名，**不传递 Priority / 强制信息**；`SchedulerEngine.cs` 亦在 T06 冻结。
- 因此 `TaskArbitrator` 通过 `ITaskService` 依赖，按 `SourceTaskId` 解析 `Priority`（`Get(...)?.Priority ?? 0`）。
- 「强制（不可被仲裁覆盖）」在冻结任务定义模型中**尚无承载字段**（UI 需求包 §8「人工冲突响应契约未冻结」），故作为**独立可注入输入** `IReadOnlySet<Guid>? forcedTaskIds`（默认空集），生产暂传空；待任务定义模型承载该标志后改为读取。
- 「落选改期 ≥ 5 分钟」在决策层以 `MinimumRescheduleDelay` 常量 + `DecisionReason` 文档化；**改期落实由消费方引擎执行，归 T09**（引擎在 T06 冻结，不改其调用点行为）。

## 3. 交付物

### 3.1 `TaskArbitrator`（新增，Core）

- 纯决策：不接触 `IPowerService`、不写日志、不写状态。
- 构造：`(ITaskService taskService, IReadOnlySet<Guid>? forcedTaskIds = null)`。
- 算法：
  1. 空集 → 无赢家（`DecisionReason = "No due instances..."`）。
  2. 单实例 → 默认胜出（`WinnerTaskId` = 该实例 `SourceTaskId`）。
  3. 任一 `forcedTaskIds` 命中 → `RequiresUserDecision=true`，`WinnerTaskId=null`。
  4. 所有实例 `ActionSnapshot` 相同 → 合并：`OrderByDescending(Priority).ThenBy(SourceTaskId)`，`WinnerTaskId` 为最大优先级（同优先级最小 id），其余入 `MergedTaskIds`。
  5. 动作不同 → `OrderByDescending(Priority).ThenByDescending(Strength).ThenBy(SourceTaskId)`；首项胜出，其余入 `RescheduledTaskIds`。
- `StrengthOf(PowerAction)`：`Shutdown=4, Restart=3, Hibernate=2, Sleep=1`，其余 `0`。

### 3.2 `LoggingTaskArbitratorDecorator`（新增，App 层）

- 包装 `ITaskArbitrator`，决策原样透传。
- `RequiresUserDecision=true` → `Warning("TaskArbitrationNeedsUserDecision", ...)`；否则 `Info("TaskArbitrated", ...)`。
- 消息含 `DecisionReason`、`WinnerTaskId`、`MergedTaskIds`、`RescheduledTaskIds`、`RequiresUserDecision`。

### 3.3 DI 注册（`ServiceRegistration`）

```csharp
services.AddSingleton<TaskArbitrator>();
services.AddSingleton<ITaskArbitrator>(provider =>
    new LoggingTaskArbitratorDecorator(
        provider.GetRequiredService<TaskArbitrator>(),
        provider.GetRequiredService<IApplicationLogger>()));
```

## 5. 测试证据（`TaskArbitratorTests`，12 项）

| 用例 | 断言 |
|------|------|
| `SameAction_MergesIntoSingleWinner` | 3 同动作 → 1 赢家 + 2 合并，无改期，`RequiresUserDecision=false`，`DecisionReason` 含 `merge` |
| `SameAction_MergedWinnerHasHighestPriority` | 同动作按优先级取最大（TaskB 90 胜），合并集按 id 排序 |
| `DifferentActions_StrengthBreaksPriorityTie` | 同优先级（0）不同动作，Shutdown 胜，其余入 `RescheduledTaskIds` |
| `DifferentActions_PriorityBeatsStrength` | 低优先级 Shutdown vs 高优先级 Sleep → Priority 优先，Sleep 胜 |
| `DifferentActions_LosersGoToRescheduledTaskIds` | Shutdown(0) vs Sleep(0) → Shutdown 胜，Sleep 改期 |
| `MinimumRescheduleDelay_IsAtLeastFiveMinutes` | 常量 ≥ 5 分钟 |
| `ForcedConflict_ReturnsRequiresUserDecision` | 强制冲突 → `RequiresUserDecision=true`、`WinnerTaskId=null`、原因含 `user decision` |
| `SingleInstance_WinsByDefault` | 单实例默认胜，无合并无改期 |
| `NoInstances_ReturnsNoWinner` | 空集 → 无赢家，无合并无改期 |
| `MissingDefinition_PriorityDefaultsToZero_StrengthDecides` | 未注册定义（Get=null）→ Priority 回退 0，强度决出 Shutdown |
| `Decorator_LogsDecision_AndPassesThroughUnchanged` | 装饰器原样透传 + 记 `TaskArbitrated` |
| `DoesNotDependOnPowerService` | 反射断言构造参数与字段均无 `IPowerService` |
