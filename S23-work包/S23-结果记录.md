## 检查点执行

### CP1 威胁模型与协议（提交 `b1cd988`）

- **方法冻结**（`RemoteProtocol`）：`pair` / `queryStatus` / `listTasks` / `triggerShutdown` /
  `cancelShutdown`；JSON-RPC 2.0，`jsonrpc/id/payload/hmac` 信封。
- **错误码**（`RemoteErrorCode`）：`Unauthorized=-32603`、`Forbidden=6`、`TaskNotFound=7`、
  `ExecutionRejected=8`、`TaskDisabled=9`、`InvalidPayload=10`，外加
  `PairingFailed/TlsRequired/UnsupportedVersion/MethodNotFound/InvalidParams/ServerNotReady`。
- **消息大小上限** `RemoteProtocol.MaxRequestBytes`（超限 `InvalidPayload`）、畸形 JSON
  `ParseError/InvalidRequest`。
- **时间窗** ±5 分钟；**nonce 生命周期**：有界防重放缓存（≤10000 条）。
- **审计字段**（`IRemoteAuditLog`/`FileRemoteAuditLog`）：时间戳/来源 IP/方法/结果/消息；契约
  明确绝不包含 PIN/secret/HMAC/私钥。
- **白名单独立冻结**：`RemoteCommandWhiteList` 独立于 S19 本地命令白名单，默认仅只读查询。
- **绑定地址/防火墙/证书信任**：默认监听 `127.0.0.1:48620`，局域网监听需放行入站 TCP；
  自签名/导入证书支持（见 CP3）。

### CP2 配对与鉴权（提交 `38e2dc2`）

- **`PairingService`**：本地 UI `RotatePin()` 生成 6 位 PIN（10 分钟有效）；`AttemptPairAsync`
  先查持久锁定、再校验有效 PIN、常量时间比对（`FixedTimeEquals`）、成功生成 32 字节 CSPRNG
  secret → `ISecretProtector.Protect` 落盘（DPAPI）→ 登记设备、清零锁定、消费 PIN（一 PIN 一配）。
- **失败限速/持久锁定**：连续 5 次失败锁定 15 分钟（`remote-pairing-lock.json` 持久化，`IClock`
  可测），锁定期间拒绝配对，仅本地 UI `UnlockAsync` 可解锁。
- **`RemoteAuthenticator`**：对信封中**原始 payload 字符串**做 HMAC-SHA256 常量时间校验
  （hex 小写）；时间戳窗口 ±5 分钟；nonce 防重放缓存；鉴权不依赖来源 IP（IP 仅审计）。
- **设备存储**（`RemoteDevicesStore`）：`remote-devices.json`，`ProtectedSecretBase64` 为 DPAPI
  封装的 secret，validation 拒绝空 secret 设备（Invalid）；读取区分 NotFound/Corrupt/Invalid/
  UnsupportedVersion，损坏 fail-closed 不执行任何电源动作。

### CP3 TLS 与服务（提交 `e10a662`）

- **`RemoteCertificateService`**：自签名 RSA-2048（CN=AutoShutdown Remote Server，SAN
  localhost+127.0.0.1，1 年）自动生成，PFX 经 DPAPI 封装后落盘 `remote-server-cert.dpapi`
  （重启解密恢复）；支持导入 PFX（`UseImportedCertificate` + `ImportedCertPath`）。
  **关键发现**：`X509KeyStorageFlags.EphemeralKeySet` 被 SChannel 拒绝用于 SslStream 服务端
  鉴权；改用 `DefaultKeySet` 且验证零残留（类内注释已记录该选型依据）。
- **证书失败一律 fail-closed**：过期/无私钥/解密失败/导入文件缺失 → 强制 TLS 时服务器拒绝启动
  监听，绝不带坏证书继续服务。
- **`RemoteServer`**：TCP 单请求服务；启动/每连接按当前 `remote-settings.json` 裁决（未启用/
  损坏/非法一律不监听）；`RequireTls=true` 拒绝明文连接（`TlsBlocked`）、`RequireTls=false` 明文
  仅以 `IsTls=false` 进入处理器（pair 与无人值守等效确认在处理器层仍强制 TLS）；
  传输/解析/握手异常直接关连接，绝不执行远程命令。**RemoteServer 只向本地服务提交授权请求，
  不调用 IPowerService**。
- **远程命令入引擎**：`SchedulerCommands` 新增 `RemoteTriggerTaskCommand`/`RemoteCancelTaskCommand`；
  `SchedulerEngine` 新增对应 `SubmitAsync` 仲裁路径（与 S22-D2 外部触发共用唯一接入/仲裁路径）。

### CP4 命令与组合矩阵（提交 `bd1021d`）

- **`RemoteRequestHandler`**：pair 强制 TLS；其余方法 HMAC 鉴权 → 白名单 → 只读查询
  （`queryStatus`/`listTasks` 返回引擎快照）→ 触发（`triggerShutdown`/`cancelShutdown`）。
- **`RemoteTriggerShutdown` 判定次序**：白名单 → 解析 taskId → 任务存在+启用 → TLS 等效门
  （`UseUnattended && !IsTls → ExecutionRejected`）→ `SubmitAsync(RemoteTriggerTaskCommand(taskId,
  equivalent))`；成功以响应 `Error==null` 判定。
- **四场景组合矩阵**（`S23_CP4_CommandMatrixTests`）：
  1. 任务无人值守 + TLS → 等效确认（`equivalent`）；
  2. 任务无人值守 + 无 TLS → `ExecutionRejected`，绝不回退本地倒计时绕过无人值守策略；
  3. 任务人工确认 → `countdown`（本地 Workflow 双闸门原样生效）；
  4. 白名单关闭/任务缺失/已禁用/鉴权失败 → `Forbidden/TaskNotFound/TaskDisabled/Unauthorized`，
     引擎未收到任何命令（fail-closed）。
- **只读命令**：`queryStatus`/`listTasks` 默认白名单开启，仅返回快照，无副作用。
- **本地策略不可写**：处理器只读 `context.WhiteList`，全程无 `SaveAsync/Write/Update/Delete` 调用
  （源码契约 + grep 双证据）。

## 关键安全不变量核对

- **唯一电源出口**：`IPowerService` 仅被 `ShutdownWorkflow` 消费（`GuardedPowerService` 为双闸门
  包装）；`RemoteRequestHandler` 类注释与实现均明确「绝不直接调用 IPowerService/IShutdownWorkflow」；
  grep 证据：Remote 模块无 `IPowerService` 引用。远程触发只构造命令经
  `SchedulerEngine.SubmitAsync` 唯一仲裁路径交回本地 Workflow。
- **远程不写本地策略**：`RemoteRequestHandler` 只读 `context.WhiteList`，无
  `SaveAsync/Write/Update/Delete`；`RemoteServer` 仅 `LoadAsync` 读取设置。grep 证据：App Remote
  目录写路径仅 `FileRemoteAuditLog.AppendAllText`（审计，不含敏感材料）。
- **Secret/PIN/HMAC/私钥绝不明文落盘或日志**：`DpapiSecretProtector.Protect`（`ProtectedData.
  Protect`）封装全部 secret；`RemoteCertificateService` 写盘前 `Protect(pfx)`；`RemoteDevicesStore`
  仅存 `ProtectedSecretBase64`；`IRemoteAuditLog`/`FileRemoteAuditLog` 契约与实现不含任何敏感材料
  （grep 证据：写盘调用点均为 DPAPI 保护或审计）。
- **fail-closed**：配置损坏/未知状态/鉴权失败/证书失败/传输异常 → 一律不执行电源动作、拒绝监听、
  关闭连接；测试覆盖（HMAC 错误/时间窗/重放/畸形 JSON/超限/证书错误/降级拒绝/白名单关闭/任务缺失
