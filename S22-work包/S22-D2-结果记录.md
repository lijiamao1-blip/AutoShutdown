## 返修结论

**通过。**

S22 独立验收发现的安全缺口：`ExternalTaskTriggerService` 收到 Windows Task Scheduler 的
`--trigger-task <id>` 回调后，直接构造 `Executing` 实例并调用 `IScheduledTaskHandler.HandleDueAsync`，
绕过了 `SchedulerEngine` 的单一实例仲裁、Confirming 倒计时边界裁决、S20-D1 无人值守有效授权裁决
与 S20-D2 Idle 输入恢复/输入未知 fail-closed 逻辑。

D2 将外部触发改道进本地调度引擎的唯一接入/仲裁路径：回调只携带稳定本地任务 id，经
`ExternalTriggerTaskCommand` + `SubmitAsync`（唯一命令通道）进入引擎，引擎内完成并发去重
（同一任务、同一触发窗口只一次有效执行），并复用 `EnterExecutingAsync` 使 Confirming→Running→
Executing、人工确认、无人值守授权、Idle 输入边界全部原样生效。返修前后 S20-D1/D2 与冻结边界
（本地 `TaskCollection` 唯一事实源、单向同步、无 inbound 写入、唯一 `IPowerService` 出口、冻结
状态机、双闸门、Pre-Pipeline 顺序）保持不变。四类集成测试新增并实际运行通过；原 S22 相关测试与
源码契约测试无回归。

## 关键安全不变量核对

- **唯一接入路径（目标 1）**：`ExternalTaskTriggerService` 不再引用 `IScheduledTaskHandler` /
  `HandleDueAsync`（源码 grep 零命中）；外部触发只经 `SubmitAsync(ExternalTriggerTaskCommand)` 进入
  引擎。源码契约 + `Trigger_EnabledOnSchedule_RoutesThroughEngineToHandler` 覆盖。
- **并发去重（目标 2）**：引擎 run-loop 先 `TryProcessDueAsync` 再读命令通道（本地到期优先），
  `IsExternalTriggerRedundant`/`SameFiringWindow` 裁决同一任务同一触发窗口只一次有效执行。
  集成测试：本地先到期 → 外部触发 Deduped、单次电源调用；本地 Waiting 实例持有窗口 → 外部触发
  Deduped、零电源调用。
- **Idle 外部触发遵守 S20-D2（目标 3）**：`ResolveCountdownConfirmationAsync` Idle 块
  （第 969-1003 行）——输入监视器缺失、任务定义缺失、空闲时长未知一律 `CancelIdleBoundaryAsync`
  fail-closed；空闲时长低于有效阈值（输入已恢复）→ `CancelIdleTriggeredAsync`（标记
  IsIdleRecovered）。集成测试：输入恢复 / 输入未知 / 监视器缺失 / 任务定义缺失 → 均不执行、零电源。
- **显式无人值守遵守 S20-D1（目标 4）**：`UseUnattended` 块（第 1001-1030 行）——评估器/策略缺失、
  策略抛异常、`!decision.AllowsPower` 一律 `CancelUnattendedAsync`，不绕过人工确认。集成测试：
  授权失效 / 策略异常 → 取消、零电源。
- **人工确认路径（检查点 3 第 5 项）**：未选无人值守的外部触发走人工确认；`RealPowerConfirmationMissing`
  → `ScheduledTaskHandlingException` → 实例 Faulted、零电源；确认有效 → 经真实 `ShutdownWorkflow`
  单次电源调用并记录 RealPowerConfirmed。集成测试两项覆盖。
- **无第二电源出口（目标 5）**：`git diff 34e5404..HEAD` 未新增任何电源操作调用行（仅 headless
  启动等待循环新增 `Thread.Sleep(20)`，非电源操作）；`Win32PowerNativeApi` / `Win32PowerService` 未改动；
  `ShutdownWorkflow` 仍是唯一允许调用 `IPowerService` 的模块。
- **冻结边界（目标 5）**：本地 `TaskCollection` 仍是唯一事实源（引擎启动 `TryLoadDefinitionsAsync`
