### 缺陷与修复

| 缺陷 | 根因 | 修复 | 回归测试 |
|------|------|------|----------|
| D1-1 取消仍可能强杀 | `WaitForExit` 一次性阻塞等待，等待返回后、强杀前无取消复核 | 可取消的有界轮询等待（100ms 轮询 + 截止时间）；强杀前 `ThrowIfCancellationRequested` 复核；取消以 OCE 传播；取消路径绝不 `ForceKill`、绝不电源 | `CancellationDuringGracefulWait_PropagatesOce_AndNeverForceKills`；`CancellationArrivesDuringWait_BeforeForceKill_PropagatesOce_AndNeverForceKills`（均断言 `ForceKillCalls` 为空） |
| D1-2 未知会话放行 | `SessionId != CurrentSessionId` 把 `-1`（未知）当「非当前会话」放行 | 未知会话（`SessionId == -1`）一律 `SkippedProtected` fail-closed；仅 `SessionId == CurrentSessionId` 放行 | `UnknownSessionId_IsSkippedProtected_WithoutAnyClose`（断言 RequestClose/WaitForExit/ForceKill 全 0） |
| D1-3 未知退出伪装已退出 | `HasExited` 查询异常被空 catch 吞成 `true`，把「无法确认」当「已退出」 | 三态 `ProcessExitStatus`（Unknown/Exited/Running）；查询异常返回 Unknown；绝不 `AlreadyExited`、绝不强杀，fail-closed | `ExitStatusUnknown_IsFailure_NotAlreadyExited_NoForceKill`；`ExitStatusUnknown_BlocksPipeline_AndPowerZero`（e2e power=0） |
| D1-4 未确认强杀当成功 | `Kill` 后 `WaitForExit(1000)` 返回值未检查，进程仍存活也返回 `Killed` | 强杀后确认退出（有界 3000ms）；未确认或确认查询异常一律 `ExitNotConfirmed`，绝不 `Killed` | `ForceKill_ExitNotConfirmed_IsFailure_NotForceKilled`；`ForceKillExitNotConfirmed_BlocksPipeline_AndPowerZero`（e2e power=0） |

## 关键安全不变量核对

- **永不关闭 AutoShutdown 自身**：`IsProtected` 检查 `CurrentProcessId` → `SkippedProtected`（测试覆盖）。
- **永不关闭系统关键进程**：`CriticalProcessNames` 关键名黑名单 → `SkippedProtected`。
- **永不关闭非当前用户会话进程**：`SessionId` 与当前会话不符或未知（`-1`）→ `SkippedProtected`（D1-2：未知会话 fail-closed，绝不放行）。
- **永不关闭未被明确稳定规则匹配的进程**：仅精确「可执行路径」或「进程 ID」匹配；`ProcessSnapshot` 不含窗口标题/命令行，无模糊标题匹配。
- **默认只允许优雅关闭**：先 `RequestClose`（WM_CLOSE）→ 有界等待；强杀仅在 `ForceKillAllowed` 时。
- **强杀必须逐目标显式 opt-in**：`ForceKillAllowed` 默认 false；未授权绝不 `Kill`（测试断言 `ForceKillCalls` 为空）。
- **强杀前重新核对 PID 与启动时间**：服务重读 `GetProcessById` 比对启动时间、网关 `ForceKill` 复核 `freshStart == expectedStartTimeUtc`，不符返回 `PidReuseDetected`。
- **访问拒绝/进程已退出/窗口消失/等待竞态安全收敛**：`AccessDenied`/`AlreadyExited`/`NoWindow`/`TimedOut`/`PidReuseDetected` 结构化收敛。
- **状态或身份不明确时不得强杀**：启动时间未知（default）时强杀前复核拒绝。
- **不得新增第二个电源出口**：`CloseAppsAction`/`CloseAppsService` 不触碰电源服务边界（源码契约测试断言）；`ShutdownWorkflow` 仍唯一。
- **不得使用 cmd/PowerShell/shell/批处理**：源码契约断言网关无 `DllImport`/`Process.Start`/`shutdown.exe`/`cmd.exe`/`powershell`/`taskkill`/`ExitWindowsEx`/`SetSuspendState`。
- **损坏配置不得静默回退**：配置不可用/清单非法/CloseApps 为 null → `Failed`（fail-closed），不触发任何关闭/强杀。
- **测试用替身**：全程 Fake ProcessManager/AppWindowManager/ConfigurationService；真机用例门控默认 no-op，未触发真实进程或真实电源。

**D1 返修新增不变量**

- **取消后强杀 = 0**：等待期间取消或等待超时后、强杀前取消，一律以 OCE 传播，绝不 `ForceKill`、绝不电源（D1-1 测试断言 `ForceKillCalls` 为空）。
- **未知会话全关闭/等待/强杀 = 0**：`SessionId == -1` → `SkippedProtected`，RequestClose/WaitForExit/ForceKill 全 0（D1-2 测试断言）。
- **退出状态无法确认绝不报成功**：三态 `Unknown` 绝不映射 `AlreadyExited`，绝不强杀（D1-3 测试断言）。
- **强杀未确认绝不报成功**：`ExitNotConfirmed` 绝不映射 `ForceKilled`（D1-4 测试断言）。
- **上述安全失败路径 power=0**：D1 e2e 测试断言 `PrePipelineBlocked` + 空电源请求。
