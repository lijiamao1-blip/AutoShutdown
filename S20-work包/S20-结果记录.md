## 检查点执行

### C1 策略与授权（提交 `e32898c`）

默认关闭的本地无人值守策略：`UnattendedPolicy`（`CurrentSchemaVersion=1`、`Enabled`、`AuthorizationVersion`、`AuthorizedAtUtc`、`AuthorizedAction`、`ExpiresAtUtc`、`RevokedAtUtc`、`TriggerReason`）；`UnattendedAuthorizationStore` 复用 `IStorage` 原子写入（临时文件 + 替换 + 备份），载入区分 NotFound/Corrupt/Invalid/UnsupportedVersion；`UnattendedPolicyService` 的 `EvaluateAsync` 把一切异常状态映射为 fail-closed 拒绝；`EnableAsync` 强制 `SecondConfirmationCompleted` + 合法动作 + 未来过期，版本递增（损坏记录经备份保留证据，绝不静默覆盖）；`RevokeAsync`：NotFound 无副作用成功、损坏/非法保守失败（不覆盖证据）、否则写入 `Enabled=false + AuthorizedAction=Unknown + RevokedAtUtc`。

### C2 输入与倒计时（提交 `1632600`）

`UnattendedConfirmationEvaluator`：纯函数、无副作用，在 Countdown（Confirming）到期边界统一评估。优先级：用户活动/显式取消优先（`IsIdleRecovered` 或终态 Cancelled/Faulted/Interrupted/Executed → 拒绝）；授权失效 fail-closed；仅授权有效且实例仍在 Confirming → 等效确认。单次执行唯一性由状态机 + `HasExecuted` 保证，评估器自身幂等、绝不产生重复执行。

### C3 工作流集成（提交 `4a0498f`）

`ShutdownWorkflow` 真实电源分支的双闸门之二改为「人工确认 `RealPowerConfirmed` **或** 无人值守等效确认」：经 `IUnattendedPolicyService.EvaluateAsync(action)` + `UnattendedConfirmationEvaluator.Evaluate(authorization, instance)`，等效确认时以 `PowerRequest.RealPowerConfirmed=true` 同时满足 `GuardedPowerService` 第二闸门；授权失效/评估异常返回新增 `ShutdownDecisionCode.UnattendedNotAuthorized=16`。新增审计字段 `ShutdownWorkflowResult.UnattendedConfirmation`（携带授权版本/时刻/触发原因）。**未新增第二个 IPowerService 调用方**；未改动冻结状态机、双闸门、I1-I9、Pre-Pipeline 顺序。

### C4 UI·审计·候选（提交 `32306be`）

设置页新增「无人值守（高级）」卡片：显著展示风险提示、当前状态（默认关闭/已授权/已撤销/已过期/损坏等）、授权版本/动作/时间/触发原因/有效期/撤销时间；启用走本地双重确认（两次独立 MessageBox，第二次为强制二次确认），撤销立即生效；`RefreshUnattendedAsync` 接入初始化刷新循环。R3 fail-safe 与源码契约测试：启用/禁用、撤销、过期、损坏记录、Pipeline block、唯一电源出口、默认关闭 fail-closed。

## 关键安全不变量核对

- **默认关闭（I1 默认不关机）**：无 `unattended.json`（NotFound）→ `EvaluateAsync` 拒绝，`ShutdownWorkflow` 返回 `UnattendedNotAuthorized`，电源调用为 0。
- **本地双重确认**：`UnattendedPolicyService.EnableAsync` 强制 `SecondConfirmationCompleted`；UI 两次独立确认；缺失即 `MissingSecondConfirmation` 拒绝。
- **版本化授权 + 原子写入 + 可恢复证据**：`UnattendedAuthorizationStore` 复用 `IStorage`（临时文件 + `File.Replace` + backups/），启用版本递增、损坏记录经备份保留，绝不静默覆盖。
- **撤销立即失效**：`RevokeAsync` 写 `Enabled=false + AuthorizedAction=Unknown + RevokedAtUtc`，评估返回 `Revoked` 拒绝。
- **NotFound/Corrupt/Invalid/UnsupportedVersion/Disabled/Revoked/Expired/ActionMismatch/Unavailable/评估异常 → 全 fail-closed**：`UnattendedPolicyService.EvaluateAsync` 与 `ShutdownWorkflow.ResolveRealPowerConfirmationAsync` 双保险。
- **用户活动 / 显式取消优先**：`UnattendedConfirmationEvaluator` 对 `IsIdleRecovered` 与终态（Cancelled/Faulted/Interrupted/Executed）一律拒绝；工作流层对非 `Executing` 态已先行拒绝。
- **竞态单次执行、不重复执行**：评估器纯函数幂等；单次执行唯一性由状态机 + `HasExecuted` 保证（C2/C3 测试覆盖终态后拒绝、唯一一次电源调用）。
- **唯一电源出口（I2）不变**：`ShutdownWorkflow` 仍唯一 `IPowerService` 调用方；Unattended 全部 Core 类型经源码契约断言不含 `IPowerService`/`PowerRequest`/`PowerResult`/`DllImport`/`ExitWindowsEx`/`SetSuspendState`/`shutdown.exe`/`Process.Start`。
- **不修改冻结状态机/双闸门/I1-I9/Pre-Pipeline 顺序**：仅以等效确认替代人工确认事实；`Confirming → Running → OfficeSave → RunCommands → CloseApps → 唯一电源调用` 链路不变。
- **Pipeline block 仍阻断电源**：无人值守授权有效但 Pre-Pipeline `Block` 动作失败 → `PrePipelineBlocked`、电源调用为 0（C4 覆盖）。
- **远程层只读**：`IUnattendedPolicyService` 仅暴露 `EvaluateAsync`（读）+ `EnableAsync`/`RevokeAsync`（本地写）；Unattended 类型无 `HttpClient`/`Socket`/`NetworkStream`（源码契约断言，S23 远程层未实现）。
- **无真实关机/重启/休眠/关闭真实用户应用**：全程替身 + RecordingPowerService；S19 限制继续有效（RunCommands 本地白名单默认空，D2B/D2C 未处理）。
