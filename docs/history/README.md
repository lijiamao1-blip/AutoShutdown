# 开发历史记录

这里存放 AutoShutdown 开发过程中留下的阶段记录，原先散落在仓库根目录，统一搬到这里，内容没有改动。

- `S*-WORK-ORDER.md`：各阶段（S3 ~ S12.x）的执行书 / 工作单。
- `S12.4.3.1-UI-TRUNCATION-DIAGNOSIS.md`、`S12.7-UI-FIXES-LOG.md`：界面截断诊断与修复记录。
- `S13-work包` ~ `S23-work包`：各阶段的执行书、结果记录与证据。
- `S-PKG-work包`：打包、发布、界面验收阶段的执行书、结果记录、截图与日志证据。
  `tools/test/` 下的冒烟测试脚本默认把新证据写入这个目录。

这些文件只用于追溯开发过程，构建、测试和发布都不依赖它们。
