## 4. 发布包结构与命名

实际版本号必须以第 1 节检查结果为准。若确认版本为 `1.0.0`，建议使用：


轻量版说明必须明确：需要安装 **.NET 8 Desktop Runtime x64**。免运行库版说明必须明确：包体更大属于正常情况。
