# AutoShutdown V2 — S22 真机人工步骤（未执行 / 人工待验）

> 本文件按 S22 执行书 CP4「真机确认任务可见、更新、删除和冗余触发；输出卸载清理清单给 S-PKG」
> 生成。下列步骤需在真实 Windows 桌面环境人工执行并逐项勾验；**自动化阶段未执行，全部标记为
> 「未执行/人工待验」，绝不写成已通过。** 电源执行部分必须以受控方式验证（仅让外部任务回调本地
> 应用并观察日志/实例，或配合无人值守等效确认），任何情况下不得让自动化测试触发真实关机。

前置：以普通用户身份安装/构建 Release 产物
`src/AutoShutdown.App/bin/Release/net8.0-windows/AutoShutdown.App.exe`，且已登录交互式桌面
（外部任务以 `InteractiveToken` 注册，只能以当前用户身份回调）。

## A. 任务可见（未执行/人工待验）

1. 打开应用「设置」→「Windows 任务计划程序同步」，勾选「启用计划任务同步」；等待状态变为
   「已启用（正在同步…）」→「同步完成：新增 N…」。
2. 打开 `taskschd.msc`（任务计划程序）→ 库 → `AutoShutdown V2` 目录。
3. 核对：目录中应出现与本地每个任务一一对应的 `AutoShutdownV2::<taskId:D>` 任务；
   触发类型与本地一致（一次性/每日/每周/每月的第几周星期几/空闲）；动作为
   `AutoShutdown.App.exe --trigger-task <taskId:D>`，**不得**出现任何电源命令参数。
4. 预期：全部通过。未执行，待人工点验。

## B. 更新（未执行/人工待验）

1. 在应用「任务管理」修改一个已同步任务的触发时间（或启停）。
2. 等待 >800ms（协调器防抖窗口）后再次打开 `taskschd.msc` 核对对应 `AutoShutdownV2::<id>`。
3. 预期：外部任务已更新（如每日触发时刻变化），且重复修改后外部任务不会翻倍
   （`CreateOrUpdate` 幂等）。未执行，待人工点验。

## C. 删除（未执行/人工待验）

1. 在应用「任务管理」删除一个已同步任务。
2. 等待防抖后核对 `AutoShutdown V2` 目录：对应外部任务应被删除。
3. 在任务计划程序中手工创建 `AutoShutdownV2::<非 D 格式或其它 guid>` 伪任务，再删除一个
   本地任务；预期该伪任务**不被**删除（三重条件）。
4. 预期：全部通过。未执行，待人工点验。

## D. 冗余触发（未执行/人工待验）

1. 在 `taskschd.msc` 中对某个 `AutoShutdownV2::<id>` 任务右键「运行」。
2. 预期：应用被拉起（无窗口、headless），日志（`%LocalAppData%\AutoShutdown\logs`）出现
   `ExternalTriggerHandled`，outcome 视时间闸门为：
   - 触发落在本地调度窗口 ±5 分钟内 → `Success`（回交本地 Workflow）；
   - 触发明显偏离（伪造/滞后）→ `GateRejected`，不执行任何电源；
   - 本地任务已删除 → `TaskNotFound`；已禁用 → `Disabled`。
3. 冗余触发**只回调本地唯一调度/Workflow**，绝不直接执行电源命令；真实关机/休眠只有在任务
   双闸门与无人值守等效确认全部放行的前提下才可能发生，人工验证时应配合受控观察。
4. 预期：全部通过。未执行，待人工点验。

## E. 权限失败与修复建议（未执行/人工待验）

1. 以受限方式（非管理员、且任务计划程序对普通用户写权限受限）勾选「启用计划任务同步」。
2. 预期：UI 显示「无法访问任务计划程序（权限不足）。修复建议：以管理员身份运行本程序一次」，
   开关回滚为关闭（fail-closed），`task-sync.json` 不残留 `Enabled=true`。
3. 以管理员身份运行一次后重试，预期同步成功。
4. 未执行，待人工点验。

## F. 卸载清理证据（未执行/人工待验）

1. 按 `S22-卸载清理清单.md` 第 3 节执行卸载器清理（或人工按三重条件删除）。
2. 预期：`\AutoShutdown V2` 目录及其全部 `AutoShutdownV2::<id>` 任务消失；其它目录/任务不受影响。
3. 未执行，待人工点验。

## G. 验证前置环境要求

- 真实桌面登录会话（InteractiveToken 外部任务需要）。
- 对任务计划程序库 `AutoShutdown V2` 目录有写权限（管理员一次即可建立；普通用户读可见）。
- 观察日志：`%LocalAppData%\AutoShutdown\logs`（`ApplicationLog-*.txt`，含
  `ExternalTriggerHandled` / `TaskSync` 事件）。
