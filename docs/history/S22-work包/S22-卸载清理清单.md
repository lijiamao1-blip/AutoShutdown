# AutoShutdown V2 — S22 卸载清理清单（交付给 S-PKG）

> 用途：本清单供 S-PKG（打包/卸载器阶段）复用到「卸载时如何移除本应用在 Windows 任务计划程序
> 中创建的外部任务」。**本阶段只输出清单本身；清理动作由适配器/卸载器在真实机器上执行，且清理
> 只能匹配「专属目录 + 应用标识 + 稳定本地 id」三重条件。** 自动化绝不执行真实电源操作。

## 1. 本应用在任务计划程序中的专属命名空间

| 项 | 值 | 说明 |
|----|-----|------|
| 专属目录（任务计划程序库根下的相对路径） | `AutoShutdown V2` | 适配器 `GetOrCreateFolder` 固定使用；目录是应用专用命名空间，只放本应用的任务 |
| 应用标识（外部任务名前缀） | `AutoShutdownV2` | 常量 `TaskSyncNaming.AppIdentifier` |
| 稳定本地 id | `<taskId:D>`（32 位大写十六进制 Guid，如 `3B7C4E4D-…-ABCDEF`） | 与本地 TaskCollection 中任务的 `Id` 一一对应；`Guid.ToString("D")` |
| 外部任务全名 | `AutoShutdownV2::<taskId:D>` | 常量 `TaskSyncNaming.Separator = "::"`；稳定、天然不含 Windows 任务名禁止字符 |
| 触发类型 | TimeTrigger / DailyTrigger / WeeklyTrigger / MonthlyDOWTrigger / IdleTrigger | 与本地任务触发一一对应（近似映射经时间闸门补偿） |
| 外部动作 | `ExecAction(<AppExePath>, "--trigger-task <taskId:D>", null)` | 只回调本地应用，绝不携带电源命令 |

## 2. 清理三重条件（必须全部满足才允许删除）

1. **专属目录**：任务位于任务计划程序库根下的 `AutoShutdown V2` 目录（适配器只在
   `GetOrCreateFolder("AutoShutdown V2")` 内查询/删除）。
2. **应用标识**：任务名以 `AutoShutdownV2::` 开头（`TaskSyncNaming.TryParseOwnedTaskName`）。
3. **稳定本地 id**：任务名剩余部分可解析为 `Guid.TryParseExact(idText, "D")` 且非空 Guid。

**任一项不满足即视为「非本应用任务」，一律不得删除/更新。** 卸载器不得删除任何其它任务、
其它目录（含 `\Microsoft\Windows` 等系统目录），也不得触碰运行中的本地调度状态。

## 3. 卸载器清理动作（建议顺序）

1. 枚举目录：`taskschd.msc` / COM 打开 `\AutoShutdown V2` 目录；目录不存在视为「无外部任务」。
2. 逐个任务执行 `TryParseOwnedTaskName` 三重条件过滤；命中才 `DeleteTask(name, false)`。
   - 适配器已有等价逻辑：`WinTaskSchedulerAdapter.QueryOwnedAsync`（只返回自家任务）+
     `DeleteAsync`（删除前防御性二次校验，非自家名一律 `Invalid` 拒绝）。
3. 全部自家任务删除完成后，若 `AutoShutdown V2` 目录已空，可删除该目录本身
   （`RootFolder.DeleteFolder("AutoShutdown V2")`，带 `deleteNotActive`）；目录内若仍存在
   **非本应用**任务则**不得**删除目录（fail-closed）。
4. 删除本应用数据目录中的同步配置：`%LocalAppData%\AutoShutdown\task-sync.json`
   （`TaskSyncSettingsStore.FileName`；含 `Enabled`/`LastSyncAtUtc`）。注意：`tasks.json`
   是本地事实源（含用户任务），**不属于** S22 卸载范围，由后续数据迁移/卸载规则另行决定；
   S22 同步开启时外部任务与 `tasks.json` 一一对应，若卸载器同时移除 `tasks.json`，
   必须在同一事务内先按第 2 步清空外部任务，避免「本地事实源已无任务、外部任务仍在触发」。
5. 清理动作全程保留审计日志（被删任务名 + 删除时间 + 结果），失败逐项记录，绝不伪装成功。

## 4. 卸载器不得做的事

- 不得删除任务计划程序中任何非本应用任务（含名字形似但解析失败的任务、其它应用目录）。
- 不得执行任何电源命令；卸载只移除任务计划程序条目与配置文件。
- 不得删除/覆盖 `AutoShutdown V2` 目录之外的本应用数据（`tasks.json`、`unattended.json`、
  `target-machines.json`、`logs` 等的归属由 S-PKG 卸载规则统一决策）。

## 5. 验证清单（卸载器自检）

| 验证项 | 预期 |
|--------|------|
| 开启同步并创建若干本地任务 → 任务计划程序出现对应 `AutoShutdownV2::<id>` 任务 | 通过（人工真机复核，见 `S22-真机人工步骤.md`） |
| 卸载器运行后 → `\AutoShutdown V2` 目录及其全部自家任务消失 | 通过（人工真机复核） |
| 卸载器运行后 → 其它目录/任务不受影响 | 通过（人工真机复核） |
| 任务计划程序中存在非本应用同名前缀任务（如他人伪造 `AutoShutdownV2::xxx` 且非 D 格式 Guid） | 绝不删除（三重条件第 3 项失败） |

## 6. 交给 S-PKG 的输入

- 常量引用：`AutoShutdown.Core.Scheduling.TaskSchedulerSync.TaskSyncNaming`
  （`DedicatedFolderPath`、`AppIdentifier`、`Separator`、`BuildTaskName`、
  `TryParseOwnedTaskName`）。
- 适配器参考实现：`WinTaskSchedulerAdapter.QueryOwnedAsync` / `DeleteAsync`
  （App 层，`Infrastructure/TaskScheduler`）。
- 同步配置：`%LocalAppData%\AutoShutdown\task-sync.json`（`SchemaVersion=1`）。
