## 4. 已知疑点（供执行者参考，不作为结论）

- 首页内容被整体包裹在 `Viewbox Stretch="Uniform"` 中，内部固定 `Width=900 Height=560`。理论上窗口缩小时内容等比缩放、不裁切；但**底部 Row2 使用 `Height="Auto"`**，若 Row0（创建任务/当前任务）内容高度超预期，Row2 会被压缩甚至溢出，可能出现底部卡片被压扁或内容超出卡片。
- 状态卡片 `MinHeight=108`，三张卡片放入 `UniformGrid Columns=3`，若可用宽度不足，卡片可能被横向压缩。
- 配置状态文本 `TextWrapping="Wrap" MaxWidth=120`，当状态文案较长时可能撑高卡片，与"最近活动"卡片高度不一致。
- `Viewbox` 的 `Margin=12` 加上窗口底部可能存在的系统任务栏/缩放比例，实际可见高度可能不足 560。
