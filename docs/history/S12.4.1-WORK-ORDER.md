## 1. 阶段目标

1. 新用户首次启动时，可以通过**明确、可见、需人工确认**的操作初始化一份安全配置。

5. 保持现有安全边界：真实电源仍不可用，所有任务只由 `FakePowerService` 模拟记录。
6. 完成构建、自动化测试、人工验收后，重新生成 S12.4 安全发布包及哈希清单。

## 3. 强制安全边界

1. 不得在配置加载失败时返回 `new AppConfig()` 冒充成功。
2. `Missing`、`Corrupt`、`Invalid`、`IoFailure`、`UnsupportedVersion`、`TestMode=false` 仍必须默认拒绝调度。
3. 只有配置状态为 **Missing** 时，才允许显示“初始化安全配置”入口。
4. 初始化必须由用户主动点击并确认；不得在启动时自动创建配置。
5. 必须调用现有 `IConfigurationService.SaveAsync` 和既有原子存储链；禁止在 UI 中直接使用 `File.WriteAllText`、`FileStream` 或自行拼接 JSON。
6. 初始化配置必须满足：
   - `SchemaVersion = 1`；
   - `TestMode = true`；
   - `AllowedActions` 仅包含 `Shutdown`、`Restart`、`Sleep`、`Hibernate`；
   - 不得包含 `Unknown`；
   - 不得包含命令、脚本、应用强杀、Wake-on-LAN、自启动或其他高风险扩展字段。
7. 配置保存成功后必须重新调用 `LoadAsync` 读取并校验真实落盘结果，确认成功后才能更新界面状态和启用创建按钮。
8. 配置损坏、格式无效、版本不支持或 IO 失败时，不得自动覆盖；只显示明确中文错误。
9. `IPowerService` 必须继续注册为 `FakePowerService`。
10. 禁止新增 `Win32PowerService`、P/Invoke、`shutdown.exe`、`Process.Start`、PowerShell 电源命令或其他真实电源路径。
11. 不得写入真实注册表，不得启用开机自启动。
12. 不得引入 claim、lease、Revision、第二调度循环或跨进程协调机制。
13. 不得删除用户数据、开发环境、诊断证据或现有发布包。
14. 不进入 S12.5。

## 4. 首次运行安全配置初始化

### 4.1 界面状态

当配置状态为 `Missing` 时：

1. 配置状态卡显示：`尚未初始化安全配置`。
2. “创建任务”按钮保持不可用。
3. 在创建区域显示一个清晰按钮：`初始化安全配置`。
4. 同一区域显示说明：`初始化后仍为安全测试模式，不会执行真实关机、重启、睡眠或休眠。`
5. 不得只显示红色错误后让用户无路可走。

### 4.2 人工确认

点击“初始化安全配置”后显示确认对话框，文案至少说明：

- 将创建新版安全配置文件；
- `TestMode` 将保持开启；
- 仅允许四种基础动作的模拟执行；
- 不会启用真实电源、自启动、脚本或应用强杀；
- 用户可以选择“确认初始化”或“取消”。

用户取消时：零写入、零状态变化。

### 4.3 保存与重读

确认后执行：

1. 构造符合第 3 节要求的安全配置。
2. 调用现有 `IConfigurationService.SaveAsync`，只允许调用一次。
3. 保存失败：显示具体中文原因，保持创建按钮不可用，不得假报成功。
4. 保存成功：立即调用 `LoadAsync` 重新读取。
5. 重读成功且校验通过：显示 `安全配置已初始化` / `安全有效`，刷新创建按钮状态。
6. 重读失败：显示实际错误，继续保持创建按钮不可用。
7. 提交过程中防止重复点击和重复写入。

## 5. 创建任务可用性与反馈

1. 在引擎为 `Running`、配置安全有效、无活动任务且输入合法时，“创建任务”按钮必须可用。
2. 用户创建 10—30 秒短倒计时任务后：
   - 命令只提交一次；
   - “当前任务”卡片显示任务状态；
   - 倒计时正常变化；
   - 下次执行时间、任务类型、提醒信息正确显示；
   - 任务完成后只产生 Fake 模拟结果，不触发真实系统电源。
3. 按钮不可用时，必须在按钮附近显示具体禁用原因。
4. 命令提交失败时，必须显示返回的实际原因，不得静默失败。
5. 不得为解决 UI 问题而修改状态机、调度器或工作流安全规则。

## 6. “首页”交互修复

1. 点击“首页”只执行“切换到首页/保持首页选中”。
2. 删除“首页”按钮触发侧边栏折叠或展开的行为。
3. 删除“首页”按钮上容易被误解为折叠入口的箭头/尖括号符号。
4. 连续点击“首页”时：
   - 左侧导航栏宽度不变；
   - 主内容区域位置不变；
   - 菜单文字和“后续开放”标签不消失；
   - 不产生横向滚动条或布局跳动。
5. 其他导航占位页及其“后续开放”状态保持不变。
6. 本阶段不新增新的侧边栏折叠按钮。
