- 出边计数：waiting 3、running 4、confirming 4、executing 3、executed 1 → **共 15**。
- 终态（cancelled/faulted/interrupted）无任何出边 → 不可逆（有专门测试断言）。

## 4. 16 个触发场景清单（测试口径）

| # | 场景 | 触发原因 |
|---|------|---------|
| 1 | waiting→running：排程触发 | ScheduleTriggered |
| 2 | waiting→cancelled：用户取消未触发任务 | CancelByUser |
| 3 | waiting→cancelled：系统判定一次性任务过期（修正 6d） | OneTimeExpired |
| 4 | waiting→faulted：配置损坏检测 | ConfigCorrupt |
| 5 | running→confirming：Pre-Pipeline 完成进入 Countdown | PipelineCompleted |
| 6 | running→cancelled：Pre-Pipeline 失败且 failurePolicy=block | PipelineFailedBlocked |
| 7 | running→interrupted：崩溃 | CrashRecovered |
| 8 | running→faulted：运行时配置损坏 | RuntimeConfigCorrupt |
| 9 | confirming→executing：用户确认 / 无人值守触发 | PowerConfirmed |
| 10 | confirming→cancelled：用户取消 / 倒计时超时且无人值守关 | CancelledDuringConfirmation |
| 11 | confirming→interrupted：崩溃 | CrashRecovered |
| 12 | confirming→faulted：确认阶段配置损坏 | ConfigCorrupt |
| 13 | executing→executed：电源操作完成 | PowerCompleted |
| 14 | executing→interrupted：崩溃 | CrashRecovered |
| 15 | executing→faulted：执行阶段异常 | PowerFailed |
| 16 | executed→waiting：重复任务下一轮排程（刷新 StageToken） | Reschedule |

- 15 条边 + `waiting→cancelled` 多一个触发场景 = **16 个触发场景**。
- 测试用两个独立 [Fact] 分别覆盖场景 2 与场景 3；另有两个白名单完整性断言：恰好 15 条边、恰好 16 个触发场景（枚举全遍历实测）。
