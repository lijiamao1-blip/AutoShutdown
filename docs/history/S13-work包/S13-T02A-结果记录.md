## 2. 集合化 CRUD 契约

### 2.1 `TaskCollection`（新增，内存领域模型，无持久化）

| 成员 | 说明 |
|------|------|
| `int Count` | 集合任务数 |
| `IReadOnlyCollection<TaskDefinition> Items` | 快照（无内部状态泄漏） |
| `TaskCollectionResult Add(TaskDefinition)` | 新增；Id 重复 → `DuplicateId` |
| `TaskCollectionResult Update(TaskDefinition)` | 更新；Id 不存在 → `NotFound` |
| `TaskCollectionResult Remove(Guid)` | 移除；Id 不存在 → `NotFound`；空 Id → `InvalidDefinition` |
| `TaskCollectionResult SetEnabled(Guid, bool)` | 分别启停；Id 不存在 → `NotFound` |
| `TaskDefinition? Get(Guid)` | 按 Id 取，未命中 null |
| `bool TryGet(Guid, out TaskDefinition?)` | 尝试取 |
| `bool Contains(Guid)` | 是否存在 |

### 2.2 校验语义（保留现有 + 新增）

- `Id` 非空（空 GUID → `InvalidDefinition`）
- `Action` ∈ {Shutdown, Restart, Sleep, Hibernate}（未知/非法 → `InvalidDefinition`）
- `Priority` ∈ [0, 100]（越界 → `InvalidDefinition`，**拒绝不截断**）

### 2.3 `TaskCollectionResult` / `TaskCollectionStatus`

- 状态：`Success / InvalidDefinition / DuplicateId / NotFound`
- 结果：`Status`、`Definition?`（Add/Update/SetEnabled 成功为落库后定义）、`Message`、`Succeeded`

### 2.4 `ITaskService` 扩展（委托给 TaskCollection）

- `Add / Update / Remove / SetEnabled / Get / GetAll`
- 现有实例生命周期命令 `Create/Snooze/Cancel/RescheduleDaily` **不变**（仍操作 `TaskInstance`）
